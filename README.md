# xList（macOS 用户指南）

xList 是一款 macOS 多存储文件管理工具。你可以在一个应用里统一管理不同存储中的文件，无需频繁切换网页或客户端。

## 适用对象
- 使用 macOS 的个人用户或小团队
- 需要统一管理多个云存储账号
- 需要可视化查看上传/下载进度和操作记录

## 安装与启动
请从 GitHub Release 下载对应架构的 `dmg` 安装包：

- Apple 芯片：下载 `arm64` 版本
- Intel 芯片：下载 `x86_64`（或 `amd64`）版本

安装步骤：

1. 双击打开下载的 `.dmg` 文件
2. 在安装窗口中，将 `xList.app` 拖到 `Applications` 快捷方式上
3. 打开“应用程序”中的 `xList.app`
4. 首次打开如遇到系统安全提示，请在“系统设置 > 隐私与安全性”中允许打开
5. 启动后按页面引导完成初始化与授权

## 首次使用流程
1. `初始化账号`
- 首次进入先设置管理员账号与密码

2. `授权激活`
- 输入授权码完成激活
- 激活成功后可进入登录页

3. `登录`
- 使用初始化时设置的账号密码登录

4. `添加存储`
- 进入“存储管理”添加你的第一个存储

5. `开始管理文件`
- 进入“文件浏览”进行上传、下载、删除、新建文件夹等操作

## 功能说明

### 1. 数据面板
用于快速了解当前系统状态：
- 已配置存储数量
- 上传任务总数与状态分布（等待中/进行中/成功/失败）
- 115 存储空间使用情况
- 下载任务数量

适合在进入系统后第一时间查看运行概览。

### 2. 存储管理
用于新增和维护存储配置。

支持存储类型：
- `115 网盘`
  - 支持 Cookie 登录
  - 支持二维码扫码登录
  - 可查看账号信息、空间使用情况、VIP 信息

- `腾讯云 COS`
  - 支持 SecretId / SecretKey 配置
  - 支持选择 Bucket、设置根路径、自定义下载域名
  - 可查看 Bucket 权限信息

你也可以在这里：
- 启用/禁用存储
- 编辑存储配置
- 删除存储

### 3. 文件浏览
用于按存储查看和管理文件目录。

你可以：
- 浏览目录结构（支持面包屑导航）
- 新建文件夹
- 上传本地文件（可批量）
- 下载文件
- 删除文件或文件夹
- 查看文件元数据（如大小、时间、标识信息等）

说明：
- 文件操作会根据存储类型自动走对应逻辑
- 界面针对 macOS 应用使用场景做了优化

### 4. 上传记录
用于查看所有上传任务的执行情况。

支持：
- 实时查看上传进度、速度、状态
- 按文件名/存储名/状态筛选
- 查看失败原因

常见状态：
- 等待中
- 上传中
- 成功
- 失败
- 已取消

### 5. 下载中心
下载中心会展示下载任务：
- 下载进度
- 速度
- 成功/失败状态
- 保存路径

同时支持：
- 取消进行中的下载
- 清理已完成任务

### 6. 查看日志
用于排查问题和观察系统运行情况。

支持：
- 查看日志文件列表
- 按文件读取最近日志内容
- 自动刷新（实时流式更新）
- 按关键字和日志级别筛选

### 7. 最近操作
用于查看系统内发生过的操作行为。

支持查看：
- 操作时间
- 操作类型（上传/下载/删除等）
- 操作对象
- 操作结果（成功/失败）
- 错误信息（若失败）

适合用于日常审计与问题追踪。

### 8. 授权管理
在“系统设置 > 授权管理”中可：
- 查看当前授权状态
- 更新授权码

### 9. 个人资料
在“个人资料”中可：
- 上传头像
- 修改登录密码

## 常见问题

### 1) 打不开 App 或提示安全风险
请在 macOS 的“系统设置 > 隐私与安全性”中允许打开该应用后重试。

### 2) 登录失败
- 确认账号密码是否正确
- 若忘记密码，请联系管理员获取重置密码方式

### 3) 存储连接失败
建议在“存储管理”中重新检查：
- 115 的 Cookie 是否有效
- COS 的密钥、Bucket、地域配置是否正确

### 4) 上传或下载失败
可在以下页面定位原因：
- 上传问题：`上传记录`
- 下载问题：`下载中心`
- 系统错误：`查看日志`

### 5) 授权问题
请联系开发者处理

### 6) 安装后无法打开应用
请先确认下载的是与你设备 CPU 架构匹配的安装包（Apple 芯片用 arm64，Intel 用 x64/amd64）。
